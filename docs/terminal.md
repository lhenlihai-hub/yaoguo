# 腰果终端使用说明

终端版直接调用腰果唯一的应用服务和 Agent loop。交互、stdin 与 JSON 只是输入输出方式不同，不会切换模型、工具集合或执行引擎。直接运行 `腰果` 时进入完整终端对话界面，不是逐行打印回复的简化壳。

## 快速开始

一行安装：

```bash
curl -fsSL https://raw.githubusercontent.com/lhenlihai-hub/yaoguo/main/install.sh | sh
```

安装完成后直接启动，中文与英文命令等价：

```bash
腰果
yaoguo
```

首次进入后输入 `/model`，选择 Pro 或 Flash、设置思考强度，并在隐藏输入中粘贴 DeepSeek API Key。也可以继续通过 `export DEEPSEEK_API_KEY="你的密钥"` 配置环境变量；非交互任务需要提前使用其中一种方式完成配置。

程序、会话、配置和记忆都收口在 `~/.yaoguo`；`~/.local/bin` 只有 `yaoguo` 与 `腰果` 两个命令链接。如果 `~/.local/bin` 尚未加入 `PATH`，安装器会更新当前 shell 的启动文件；管道脚本无法修改父 shell，因此需要新开终端，或按提示执行一次 `export PATH=...`。

## 终端对话界面

首屏显示“欢迎使用腰果”和小型字符图形，不在启动界面中展示底层依赖介绍。界面中间持续展示对话、DeepSeek 推理流、思考耗时、工具工作流与成品；底部提供多行输入框，状态栏显示完整工作空间路径、模型、思考强度、授权模式、API Key 与 token/cache 摘要。用户消息只使用蓝色字体，不使用背景色；思考过程使用弱化斜体，Agent 最终回复按 Markdown 流式渲染。

输入 `/` 会打开可搜索的命令菜单；方向键选择，`Enter` 确认，`Esc` 返回。内置命令如下：

```text
/model        模型、思考强度与 DeepSeek API Key
/usage        token、缓存命中与模型调用
/resume       打开或删除历史会话
/new          在当前工作空间新建会话
/permissions  切换 Ask / All agree 授权模式
/clear        清空当前屏幕，不删除已保存会话
/help         查看命令与快捷键
/quit         退出
```

输入框支持多行编辑、历史输入、长文本粘贴和 `@` 文件路径补全。`Enter` 发送，`Shift+Enter` 或 `Ctrl+J` 换行；任务运行时按 `Esc` 或 `Ctrl+C` 中止，空闲时按 `Ctrl+C` 或空输入下的 `Ctrl+D` 退出。需要写文件、执行命令或访问网络时，授权选项会以界内菜单出现。

默认会话与工作空间绑定。启动时优先进入当前工作空间已有的空白新任务；如果没有空白任务，就创建一个。历史记录仍保存在腰果运行目录中，`/resume` 按每个任务第一条消息生成的任务名称显示并可打开或删除；删除会清理该会话的记录和受管任务数据，已发布成品会先归档，用户工作空间中的文件不会删除。`/new` 和 `--new` 可创建独立任务。

## 卸载

```bash
腰果 uninstall
```

确认后会删除程序、命令链接、会话、配置、Token 记录、长期记忆和安装器写入的 `PATH` 片段。卸载前，任务 `final` 目录中的已发布成品会先按项目与会话归档到 `~/.yaoguo/artifacts/<卸载时间>/`。用户自己的工作目录与其中文件始终保留。

非交互脚本可以显式使用 `腰果 uninstall --yes`。

从源码运行：

```bash
npm install
export DEEPSEEK_API_KEY="你的密钥"
npm run cli -- "阅读当前目录并给出改进建议"
```

不带任务时进入连续会话：

```bash
npm run cli
```

也可从 stdin 接收单次任务：

```bash
printf '%s\n' '总结 README.md' | npm run cli
```

如果通过 `npm link` 建立了本地命令，可把 `npm run cli --` 换成 `yaoguo` 或 `腰果`。

## 参数

```text
--workspace <目录>  Agent 工作空间，默认当前目录；主目录启动时使用 ~/Yaoguo Workspace
--data-dir <目录>   运行数据目录，默认 ~/.yaoguo/runtime
--project <id>      使用或创建指定项目
--task <id>         使用或创建指定会话
-n, --new           在当前工作空间创建新会话
-y, --yes           本次进程自动授权需确认的工具操作
--json               单次任务输出 JSON
-v, --verbose        显示完整 Agent 活动
-q, --quiet          隐藏活动与本轮 token 统计
-h, --help           显示帮助
-V, --version        显示版本
```

`YAOGUO_HOME` 可设置默认运行数据目录，显式 `--data-dir` 的优先级更高。直接在用户主目录运行 `腰果` 时，CLI 会创建并使用独立的 `~/Yaoguo Workspace`，避免把包含腰果内部数据的整个主目录交给 Agent；显式指定与内部数据重叠的 `--workspace` 仍会被拒绝。首次进入一个工作空间时会创建稳定的新任务；之后普通启动优先复用空白新任务，没有时再创建。`--task` 精确打开指定历史任务，`--new` 创建独立任务。

## 模型与 API Key

交互终端即使尚未配置 API Key 也能正常打开。输入 `/model` 后通过界内菜单选择 Pro 或 Flash，并可设置 Thinking off、High 或 Max。这三项会直接写入 DeepSeek 请求的 `thinking` / `reasoning_effort`，不是界面标签。API Key 在隐藏输入框中设置，不会回显或保留在终端历史中。环境变量 `DEEPSEEK_API_KEY` 仍然有效，本机配置优先于环境变量。

直接执行单次任务或通过 stdin 调用时不会打开设置菜单；若两种位置都没有密钥，进程会返回明确错误与退出码 `1`。

## Agent 状态与 token

交互终端默认显示 DeepSeek 推理内容与思考耗时。模型进入读取、搜索、执行命令、生成、检查或发布等步骤时，当前步骤名会替代固定的 Agent 标签，完成后保留在本轮工作流中；涉及文件时显示完整路径。每轮结束后还会显示模型调用次数、输入 token、输出 token、推理 token、DeepSeek prompt cache 命中数据和本轮耗时。

```text
本轮 3 次模型调用 · 输入 12,345 · 输出 678 · 推理 120 · 缓存命中 75%（9,000/12,000） · 12.5s
```

输入 `/usage` 可读取当前会话累计数据。这个命令直接查询本地 TokenLedger，不会调用模型，也不需要消耗 token：

```text
会话累计 18 次模型调用 · 输入 84,210 · 输出 6,422 · 推理 2,041 · 前台缓存 86%（48,320/56,186） · 后台 4 次，缓存 12%
```

状态栏的 `C` 代表前台 Agent 命中率。`/usage` 仍统计全部 token，但把前台 Agent 与后台记忆、自动命名等内部调用的 prompt cache 分开显示，避免后台摘要请求把用户看到的命中率稀释。`--json` 会把本轮 `usage` 放入结构化结果；以 `--json /usage` 调用时输出累计统计对象，其中含 `foreground` 与 `background` 子项。

## 权限

安全读取、模型计算和 Agent 状态写入无需确认。修改工作空间、执行命令、访问网络、打开外部网址、使用系统应用打开本地文件或文件夹，以及写入长期记忆等操作遵循统一权限策略。本地打开只接受当前工作空间、当前任务成品区或用户本轮明确授权的路径，不能打开腰果宿主控制目录。

交互终端会显示授权目标与边界，可选择允许一次、本次进程允许、持久允许精确操作、持久允许该类型或拒绝。非交互 stdin 默认拒绝需要确认的操作；只有显式传入 `--yes` 才会在本次进程内自动授权。

`/permissions` 中的 **All agree** 是持久的全局自动同意模式；切回 Ask 后恢复逐次询问。All agree 不会取消路径边界、参数校验、无提权、私网阻断或沙箱限制，但仍只应在可信工作空间中开启。

`--yes` 不会取消路径边界、参数校验、无提权、私网阻断或沙箱限制，但仍可能允许 Agent 修改当前工作空间和执行命令。只在已审阅任务与可信目录中使用。

## 输出与退出码

任务中如果明确写入已存在的绝对目录，或写入“已存在父目录 + 目标文件名”，腰果会把它作为本轮用户授权的交付位置。成品仍会保留一份受管快照，同时复制到指定位置；它不会覆盖同名文件，而是生成 `-v2`、`-v3` 版本。未在用户当轮原话中确认的外部路径不会被 `publish_artifact` 接受。

对 PPTX、DOCX、PDF 和 XLSX 制作任务，Agent 在每次 `write` / `edit` / `bash` 中明确选择“项目区”或受管的 `.candidates` “制作区”。生成脚本、Markdown 源稿、依赖清单、预览和中间文件只留在制作区，不进入用户工作空间。默认只允许 1 个检查通过的主成品发布到绑定工作空间；用户在当轮明确要求多个独立文件、多种格式或源文件时，上限随请求数量扩大，最多 4 个。

- 不带任务的交互模式由终端 UI 管理对话、输入、菜单和状态栏。
- 单次普通模式把 Agent 正文写入 stdout，把活动、授权、成品路径和本轮统计写入 stderr。
- `--json` 关闭 token 流，在 stdout 输出项目、会话、工作空间、回复、成品和 usage。
- `--quiet` 保持 stdout 正文不变，同时隐藏 stderr 中的活动和本轮统计；授权请求仍会显示。
- 启动、配置或输入错误返回退出码 `1`；正常完成返回 `0`。

终端进程不启动 scheduler、bridge 或夜间后台任务；只有用户明确要求且授权后，Agent 才会打开系统浏览器、本地文件或文件夹。不要让两个进程同时修改同一个任务会话。
