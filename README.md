# 腰果（Yaoguo）

一个基于 [Pi](https://github.com/earendil-works/pi) 基础能力开发的本地终端 Agent。目前只支持 DeepSeek。

腰果不是把一次回复打印到 stdout 就结束的命令行脚本。直接运行 `腰果`，会进入一个持续工作的终端对话界面：上方保留对话、推理与工具活动，下方是多行输入框和状态栏；输入 `/` 会打开命令菜单。用户消息使用蓝色字体、不铺底色，思考过程使用弱化斜体，Agent 最终回复以 Markdown 实时流式更新。

腰果保留 Pi 简洁的 Agent loop 与工具调用方式，不在 Agent 外再堆叠意图路由、角色流水线或多模型调度。我们主要做了两类高层设计：一套不干预具体写法的总体审美哲学，以及一套让长期协作更连续、可维护的记忆模式。在此之上，项目补齐了宿主权限、工作空间、上下文外置、成品持久化和常用工具集。

> 项目仍处于早期阶段，接口和数据结构可能继续调整。欢迎试用、讨论和贡献。

## 为什么做腰果

我们希望 Agent 的能力来自一个可以自己判断、自己使用工具的统一循环，而不是越来越厚的外围编排。对用户而言，它应当同时具备三种品质：

- **简单**：一个 Agent、一条模型路径、一套会话真相源。
- **连续**：短期上下文、长期记忆与明确指令各司其职，不把所有历史粗暴塞回提示词。
- **可交付**：不止回答文字，也能检索、操作工作区、生成和验收真实文件。

## 完整的终端对话界面

终端版把交互本身作为产品界面，而不是一次性输出的降级形式：

- **任务优先**：启动时优先进入当前工作目录中的空白新任务；已有任务通过 `/resume` 按任务名称恢复。
- **底部输入框**：支持长文本、多行编辑、历史输入、粘贴，以及 `@` 文件路径补全。
- **蓝色消息风格**：用户消息只使用蓝色字体；Agent 回复支持标题、列表、代码块和链接等 Markdown 样式。
- **斜杠菜单**：`/model` 设置 Pro / Flash、思考强度与 API Key；`/resume` 打开或删除历史会话，`/new` 创建会话，`/permissions` 切换 Ask / All agree。
- **真实运行状态**：界面展示 DeepSeek 返回的推理流与思考耗时，并按顺序记录正在进行和已完成的工具步骤。
- **完整路径**：工作空间、工具目标和成品位置都显示完整路径。
- **Token 状态栏**：常驻显示输入、输出与前台 Agent 的 prompt cache 命中率；`/usage` 可查看当前会话完整累计数据。

常用快捷键：`Enter` 发送，`Shift+Enter` 或 `Ctrl+J` 换行，任务运行时按 `Esc` 或 `Ctrl+C` 中止，空闲时按 `Ctrl+C` 或空输入下的 `Ctrl+D` 退出。一次性任务、stdin 和 `--json` 模式仍然保留，方便脚本和自动化调用。

## 与 Pi 的关系

腰果不是 Pi 的替代品，也不是对 Pi 核心循环的重写。两者的边界如下：

| 层级 | Pi 提供 | 腰果增加 |
|---|---|---|
| Agent 核心 | Agent loop、工具调用、原生参数校验、基础文件工具、Skill 加载 | DeepSeek 适配、单 Agent 产品入口与运行状态 |
| 宿主 | 可组合的 Agent 基础能力 | 工作区权限、命令执行边界、运行数据和成品持久化 |
| 上下文 | 模型与工具交互基础 | 大输入外置、可续读工具结果、长会话压缩和 checkpoint |
| 记忆 | 可由上层应用组合 | 指令记忆、Session Memory、长期 Memdir、预取与主动沉淀 |
| 产品工具 | 基础读写与 Skill 能力 | 检索、引用、待办、成品、文档、图片和质量评估等常用工具 |

我们直接复用 Pi 适合复用的部分，只在产品层补齐腰果需要的能力。第三方来源和许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 记忆系统

腰果没有把“记忆”视为一段不断变长的聊天记录，而是按用途拆成三个层次：

### 1. 指令记忆

稳定规则、项目约定和用户偏好作为明确指令加载。不同作用域可以分别维护，并在每轮执行前生成快照，让“应该怎样工作”与“过去发生过什么”保持分离。

### 2. Session Memory

当前会话保留完成任务真正需要的决定、进度、事实和待处理项。当活跃上下文过长时，系统会先无损外置超大输入与工具结果，再对长会话生成结构化记忆；默认在 100,000 active tokens 触发压缩，避免一次性截断历史。

### 3. 长期 Memdir

跨会话信息进入 Agent 绑定的 Memdir。它支持两种互补模式：

- **可维护索引**：适合长期偏好、稳定事实和主题知识，便于检索与更新。
- **append-only 日志**：适合保留时间顺序、决策过程和不可覆盖的经历。

系统可以在回答前预取相关记忆，也允许 Agent 用 `search_memory` 查找、用 `pin_memory` 主动沉淀。后台的记忆提取与 AutoDream 负责整理候选内容，但不会让另一套 Agent 接管用户任务。

这套设计的目标不是“记住越多越好”，而是让正确的信息在正确的时刻以正确的粒度出现。

## 内置能力

腰果常驻基础文件工具，并按需揭示更专业的能力，减少无关工具占用上下文。

- **工作区**：读取、写入、精确编辑文件，在受控目录执行命令，并按用户要求使用系统应用打开允许范围内的文件或文件夹。
- **研究与引用**：搜索参考资料、抓取网页、分页读取本地资料、搜索图片、管理引用。
- **任务与交接**：维护待办、记录决定与事实、检索前序运行产物。
- **记忆**：搜索长期记忆、主动保存关键事实或偏好。
- **成品交付**：检查、发布或废弃候选成品，保留可追踪的交付记录。
- **文档工具集**：创建、读取、校验和预览 DOCX、PDF、PPTX、XLSX。
- **质量与扩展**：按需调用证据型质量评估、加载能力或运行 Skill。

所有任务仍由同一个 Agent 决定何时回答、读取文件、执行命令、调用工具或交付成品。

## Token 与缓存统计

交互模式会显示 Agent 当前活动、工具调用和本轮耗时。每轮结束后输出真实的模型 usage，例如：

```text
本轮 3 次模型调用 · 输入 12,345 · 输出 678 · 推理 120 · 缓存命中 75%（9,000/12,000） · 12.5s
```

`/usage` 可查看当前会话累计输入、输出和推理 token。前台 Agent 与后台记忆、自动命名等内部调用的缓存分开统计，状态栏的 `C` 只显示前台命中率。这里的“缓存”是 DeepSeek API 返回的 prompt cache usage，与腰果的长期记忆不是同一机制。

## 要求

- Node.js `22.19.0` 或更高的 Node 22 版本
- macOS 或 Linux
- DeepSeek API Key
- 可选：LibreOffice，用于部分文档预览和格式转换

## 开始使用

推荐使用一行安装（不需要 `sudo`）：

```bash
curl -fsSL https://raw.githubusercontent.com/lhenlihai-hub/yaoguo/main/install.sh | sh
```

安装后可以直接启动：

```bash
腰果
```

首次进入后输入 `/model`，选择 Pro 或 Flash、设置真实的 Thinking off / High / Max 思考强度，并通过隐藏输入保存 DeepSeek API Key。也可以继续使用 `export DEEPSEEK_API_KEY="你的密钥"`；单次命令和 stdin 等非交互调用需要提前完成其中一种配置。

`yaoguo` 是等价的英文命令。程序、运行数据与记忆统一放在 `~/.yaoguo`，只在 `~/.local/bin` 留下两个命令链接。安装前可先在浏览器中[审阅脚本](install.sh)；已知上游依赖例外见[生产依赖安全记录](docs/DEPENDENCY_SECURITY.md)。

完全卸载：

```bash
腰果 uninstall
```

卸载器会删除程序、命令链接、会话、配置、Token 记录和长期记忆，并清理安装器写入的 `PATH` 配置。已发布成品会先归档到 `~/.yaoguo/artifacts`；用户工作目录中的文件不会被删除。

开发者也可以从源码安装：

```bash
git clone https://github.com/lhenlihai-hub/yaoguo.git
cd yaoguo
npm install
export DEEPSEEK_API_KEY="你的密钥"
npm run cli
```

也可以直接运行一次任务：

```bash
npm run cli -- "阅读当前项目并说明它的结构"
```

或者从 stdin 输入：

```bash
printf '%s\n' '总结 README.md' | npm run cli
```

通过一行安装或 `npm link` 建立命令后，可以直接使用：

```bash
腰果
yaoguo
yaoguo "检查当前目录中的测试失败"
```

内置终端命令：

```text
/model        模型、思考强度与 DeepSeek API Key
/usage        token、缓存命中与模型调用
/resume       打开或删除历史会话
/new          在当前工作空间新建会话
/permissions  切换 Ask / All agree 授权模式
/clear        清空当前屏幕，不删除已保存会话
/help         查看命令与快捷键
/quit         退出
```

如果希望成品出现在指定目录，可以直接在任务中写绝对路径，例如“请把课件保存到 `/Users/me/Courseware`”。腰果会保留可追踪的受管快照，同时把成品复制到用户明确指定的位置；同名文件会创建新版本，不覆盖原文件。

制作 PPTX、Word、PDF 或 Excel 时，源稿、生成脚本、依赖清单、预览和中间文件会留在任务的隐藏制作区。用户没有明确要求多个文件或源文件时，工作空间只收到 1 个检查通过的主成品。

脚本环境可使用 `--json` 获得结构化结果，或用 `--quiet` 隐藏活动与本轮统计。完整参数与权限行为见 [终端使用说明](docs/terminal.md)。

## 模型边界

腰果只支持 DeepSeek V4 Pro / Flash。模型请求统一经过 `ModelGateway`，不会根据任务类型切换到其他提供商，也没有备用模型或第二套 Agent 引擎。

API Key 只从 `DEEPSEEK_API_KEY` 或本地配置读取，不接受命令行明文密钥。运行数据默认保存在 `~/.yaoguo/runtime`，当前目录只作为 Agent 工作空间；直接从用户主目录启动时会改用独立的 `~/Yaoguo Workspace`。
